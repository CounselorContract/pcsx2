# PCSX2

### PlayStation 2 emulator with full HD support

PCSX2 is the most advanced PlayStation 2 emulator available, capable of running thousands of PS2 games at full speed with enhanced resolutions, widescreen support, and texture filtering far beyond original hardware.

<br>

---

## Features

| | |
|:---|:---|
| **4K Support** | Render PS2 classics at 4× or 8× internal resolution on modern displays |
| **Wide Compatibility** | Over 2,500 games playable including most major titles |
| **Widescreen Patches** | Community patches add 16:9 widescreen support to hundreds of games |
| **Retroarch Core** | Available as a RetroArch core for unified emulation management |
